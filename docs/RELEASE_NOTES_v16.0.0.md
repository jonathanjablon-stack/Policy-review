# Stop-Loss Policy Review Workbench v16.0.0

Version 16 replaces the v15.3b first-hit regex workflow with an occurrence-preserving, clause-first review workbench.

Highlights:

- four full review modes;
- structured Policy at a Glance;
- amendment and endorsement hierarchy;
- concept-paired comparisons;
- separate classification, severity, and confidence;
- 136 inspectable deterministic rules;
- attorney-controlled dispositions and exports;
- explicit unreadable-page handling;
- save/reopen sessions;
- archived v15.3b rollback source;
- complete source, build, tests, QA, and documentation.

The production artifact is `dist/StopLoss_Workbench_v16.0.0.html`; root `index.html` is the deployment entry point.
